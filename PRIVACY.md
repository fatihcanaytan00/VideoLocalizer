# Privacy Policy - VideoLocalizer

VideoLocalizer is a personal software tool that uses the YouTube Data API to localize video metadata and captions.

Data Usage:
- The application accesses YouTube video metadata and caption information only for localization purposes.
- OAuth credentials and access tokens are stored locally and are not shared with third parties.
- The application does not collect, sell, or transmit personal user data.

YouTube API Services:
This application uses YouTube API Services and complies with the YouTube API Services Terms of Service.
