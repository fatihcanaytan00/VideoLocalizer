# Terms of Service - VideoLocalizer

## Overview

VideoLocalizer is a personal software tool designed to help content creators localize their YouTube videos by translating video metadata and caption tracks into multiple languages.

The application uses YouTube API Services to access and manage content owned by the authorized user.

## Use of YouTube API Services

VideoLocalizer uses YouTube API Services to:

- Retrieve video metadata such as titles and descriptions.
- Create and update localized metadata.
- Retrieve existing caption tracks.
- Translate and upload caption tracks in multiple languages.

The application only accesses YouTube content that the user has authorized through Google OAuth.

## User Responsibilities

Users are responsible for:

- Maintaining control of their Google account.
- Ensuring that they have the necessary rights to modify the videos and captions processed by the application.
- Using the application in compliance with YouTube's Terms of Service and applicable laws.

## Data Handling

VideoLocalizer does not sell, share, or distribute user data.

OAuth credentials and access tokens are stored locally on the user's device and are only used to communicate with authorized Google services.

## Availability

VideoLocalizer is provided as a software tool without guarantees regarding uninterrupted availability or error-free operation.

The user accepts responsibility for reviewing translated content before publishing.
